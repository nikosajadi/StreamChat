# Chat background art

Drop a picture here named `wallpaper.jpg` and it replaces the drawn background behind the messages. Nothing else to change: `components/ui/ChatBackground.tsx` looks for this file at build time and uses it if it's there.

It's shown faded (about 12% opacity) so text stays readable in both themes. Something soft and not too busy works best.

Delete the file to go back to the generated watercolor shapes.
